# NotchShot audit — 28 October 2026

Twelve confirmed findings were repaired, including lost History after failed
recovery and approvals without complete action details. All 1,182 selected tests
in 198 suites pass; Debug and Release builds pass. This is a point-in-time
assessment of source and fixtures, with explicit UI, hardware and service gaps.

## Charter and source state

Audit and focused repairs requested across the complete macOS app: correctness,
security/privacy, persistence/data loss, concurrency/cancellation, performance,
UX/accessibility, reachability/duplication, dependencies/build and test gaps.
Preserve existing behavior, UI, architecture, data and public contracts.

- Baseline: `6fc82ef`, branch `codex/liquid-glass-notch`; initial tree clean.
- Local app: Swift Package Manager, Swift language mode 6, minimum macOS 26.
- Scope: shipped app/library, auxiliary tools, build/release configuration, tests;
  promotional video projects receive configuration inventory only.
- Acceptance/stopping point: every discovered major feature and category has a
  source-review disposition or explicit gap; significant candidates are confirmed,
  rejected or classified as unresolved; confirmed in-scope repairs have focused
  checks plus relevant baseline validation; final diff reviewed and task changes
  committed/pushed without unrelated work.
- Evidence limits: tests/model fixtures, source proof, UI/hardware and external
  services are separate. No live uploads, hook configuration edits, real captures,
  device permission changes or destructive operations on user data.
- Toolchain: `/usr/bin` Apple wrappers initially fail because the Xcode license is
  unaccepted. `DEVELOPER_DIR=/Library/Developer/CommandLineTools` provides Swift
  6.3.3; the direct CLT Git binary works. No license/system configuration changed.
- Baseline command: `DEVELOPER_DIR=/Library/Developer/CommandLineTools swift test
  --no-parallel --skip PasteboardRaceTests`; general-clipboard mutation excluded.
  Temporary raw evidence: `/tmp/notchshot-audit-2026-10-28/` (local, not committed).
