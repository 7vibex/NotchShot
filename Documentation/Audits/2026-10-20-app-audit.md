# NotchShot audit — 20–21 October 2026

Follow-up to the [11 October audit](2026-10-11-app-audit.md), aimed at the code added since (agent integrations, Crewline, system utilities, the island design pass, the CLI). Eleven confirmed defects and one root cause were repaired and pushed to `main`. Every fix but F-003, which rests on source proof, has a regression test. The final tree passed 1,085 tests in 177 suites. This was a risk-ordered subsystem audit, not a claim that every interaction was exercised; the gaps are listed at the end.

## Scope and method

- Started at `da9b16a` with a clean tree. New code with security, IPC, file-system or destructive surfaces came first, then known open defects, then a sample of older pipelines.
- Each candidate was traced from entry point to side effect, then reproduced with a fixture, probe or render before any fix. The tests for the F-009 and F-011 fixes were mutation-checked (they fail without the fix).
- Constraints: the user's clipboard was not touched (`PasteboardRaceTests` skipped), the running `dist/NotchShot.app` was not restarted, hook configs were read-only, and no live Crewline or other network service was called. Transcripts were measured by size and count only.
- Another session committed on `main` in parallel. Its files were never staged here.

## Rejected candidates

- Zip-slip and symlink traversal in archive extraction: ditto strips `../` and refuses to write through a symlink; bsdtar refuses too.
- A hook timeout shorter than the question bridge's wait: Claude Code's command hooks default to 600 s, so the 120 s and 300 s waits fit.
- cfprefsd keeping preferences after App Reset: a runtime probe with a dummy domain showed the reset takes effect.
- Accessibility value force casts crashing: `AXValueGetValue` validates the type and returns false.
- Freeze-frame capture bypassing window exclusions: it uses the same exclusion set as live capture.

## Risks and product decisions left as they are

- **System microphone mute** (`MeetingControls`): for calls in apps without a known shortcut, such as browsers, the island mutes the default input for every app and never restores it when the call ends. That also silences NotchShot's own dictation later, and the island shows a cached state that can go stale after an input-device switch.
- **Floating basket Tab key**: the panel uses Tab and Shift-Tab to cycle baskets, so Full Keyboard Access users cannot Tab between its controls. ⌘1–⌘5 and VoiceOver are unaffected.
- **LocalSend** pins a file's identity when Send is pressed, not when it is chosen on the shelf. A replacement made while the device picker is open is sent; symlinks are still refused.
- `notchshot-ai run` has no heartbeat, so a command running longer than 30 minutes leaves the island while still running. `notchshot-cli` has one.
- tmux pane selection runs `tmux` synchronously on the main actor, without a timeout.
- After RC-1, a forged inode, size and mtime on a different volume behind a swapped path would pass. Comparing a stored volume UUID when `st_dev` differs would restore that check.
- `LyricsService` checks the size after a download completes; the 12 s timeout bounds it.

## Validation

- Final full suite on a clean tree at `ca3e2de`: 1,085 tests in 177 suites passed (`swift test --no-parallel --skip PasteboardRaceTests`). `Scripts/check_hygiene.sh` and `git diff --check` passed.
- 8d95866 and 936452e were each built from a clean `git archive` export before publishing, without the other session's uncommitted files.
- Runtime evidence came from the symlink-swap upload probe, the pty comparison of direct and wrapped commands, the before and after chip renders, the reproduced JSON crash, and quarantine xattrs on extracted files.

## Coverage gaps

- No signed release build or notarization: the signing keychain can't be used from an agent session.
- No live, on-screen check of the island, agent rows or reply chips. The island is hidden from screenshots and the user's running instance was not restarted, so renders were offscreen.
- No live Crewline, Zoom, Teams, Slack or Discord session. The iTerm2 script was not compiled because iTerm2 isn't installed. The F-003 descriptor fix was not exercised at runtime.
- Not checked: whether Claude Code pastes an image from a file-URL clipboard with ⌃V, because that would overwrite the user's clipboard.
- Sampled rather than exhaustively traced: CLI options, the floating basket, meeting controls, agent UI accessibility labels.

## Side effect during the audit

While reproducing F-010, the real `notchshot-cli` was run with `TMPDIR` redirected. Foundation on macOS ignores `TMPDIR`, so the CLI reached the running app's socket. A "sleep" activity showed on the island for about a minute, until it was removed with `notchshot-cli activity dismiss --id probe`. Later probes used standalone binaries compiled from `ForegroundCommand.swift` instead.
