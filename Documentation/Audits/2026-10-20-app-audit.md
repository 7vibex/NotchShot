# NotchShot audit — 20–21 October 2026

Follow-up to the [11 October audit](2026-10-11-app-audit.md), aimed at the code added since (agent integrations, Crewline, system utilities, the island design pass, the CLI). Eleven confirmed defects and one root cause were repaired and pushed to `main`. Seven follow-ups from the risk list were fixed on 21 October (F-012 to F-018). Every fix but F-003, F-013 and F-015 has a regression test. This was a risk-ordered subsystem audit, not a claim that every interaction was exercised; the gaps are listed at the end.

## Scope and method

- Started at `da9b16a` with a clean tree. New code with security, IPC, file-system or destructive surfaces came first, then known open defects, then a sample of older pipelines.
- Each candidate was traced from entry point to side effect, then reproduced with a fixture, probe or render before any fix. The tests for the F-009 and F-011 fixes were mutation-checked (they fail without the fix).
- Constraints: the user's clipboard was not touched (`PasteboardRaceTests` skipped), the running `dist/NotchShot.app` was not restarted, hook configs were read-only, and no live Crewline or other network service was called. Transcripts were measured by size and count only.
- Another session committed on `main` in parallel. Its files were never staged here.

## Rejected candidates

- Zip-slip and symlink traversal in archive extraction: ditto strips `../` and refuses to write through a symlink; bsdtar refuses too.
- A hook timeout shorter than the question bridge's wait: Claude Code's command hooks default to 600 s, so the 120 s and 300 s waits fit.
- cfprefsd keeping preferences after App Reset: a runtime probe with a dummy domain showed the reset takes effect.
- Accessibility value force casts crashing: `AXValueGetValue` validates the type and returns false.
- Freeze-frame capture bypassing window exclusions: it uses the same exclusion set as live capture.

## Follow-up repairs, 21 October

These were left as risks in the first pass and then fixed on request. Each has a regression test except F-015, whose wiring is source-checked: running the real `notchshot-ai` would write to the user's live AI Activity folder.

| ID | Area | Trigger and previous behavior | Repair and evidence | Commit |
|---|---|---|---|---|
| F-012 | Meeting mute | For calls in apps without a known shortcut, such as browsers, the island muted the default input for every app and never restored it, which also silenced NotchShot's dictation later. The island showed a cached state that could go stale after an input-device switch. | NotchShot records the device and calls it muted for, and unmutes that device once all of those calls end, if it is still muted. The state is read live from CoreAudio. Test of the hold's lifetime. | 0346c38 |
| F-013 | Floating basket | Tab and Shift-Tab cycled baskets, so Full Keyboard Access users couldn't Tab between the panel's controls. | With Full Keyboard Access on, Tab is passed through; ⌘1–⌘5 still switch baskets. Source-checked; no UI test harness for the panel. | 91d3444 |
| F-014 | LocalSend | The file's identity was read at Send, so a replacement made while the device picker was open was uploaded (symlinks were already refused). | `LocalSendSelection` pins the identity when the file is chosen (shelf, drop or open panel), and the snapshot copy refuses a replaced file. Tests for a swap after selection, a replaced shelf file, links and the size limit. | f37cae8 |
| F-015 | `notchshot-ai run` | No heartbeat, so a command running longer than 30 minutes left the island while still running. | The shared `ActivityHeartbeat` rewrites the working activity every four minutes and stops before the final report. | 7aa41b4 |
| F-016 | Terminal jump | tmux pane selection ran up to five `tmux` commands on the main actor with no timeout. | The commands share a 1.5 s budget; an overrunning one is terminated, then killed. Output is read off the waiting thread. Tests for the deadline, output over a pipe buffer, and failure status. | b7a587b |
| F-017 | File identity | After RC-1, a forged inode, size and mtime on another volume behind a swapped path would pass. | Identities store the volume UUID, and a mismatch is refused when both sides have one. Older rows decode without it and still match. The lookup is cached for 5 s per mount. Test with a stale device number and a different volume. | d8933ef |
| F-018 | Lyrics | The 2 MB bound was checked only after the full body was buffered; a server that kept sending held the lookup until the 12 s timeout. | The answer is streamed and refused once it crosses the bound or announces a larger length. A stub server that never finishes is now refused in about 2 s in a debug build, instead of hanging. | 5e304aa |

Residuals:
- The approved media helper's exec-time re-check gets no volume argument, so only the app-side check tells volumes apart.
- F-012 releases the mute when NotchShot sees the calls end. If NotchShot quits during a call, the mute stays until the user turns the mic back on.
- F-013 and F-012 were not exercised on screen or in a live call.

## Validation

- Final full suite on a clean tree at `ca3e2de`: 1,085 tests in 177 suites passed (`swift test --no-parallel --skip PasteboardRaceTests`). `Scripts/check_hygiene.sh` and `git diff --check` passed.
- Follow-ups at `5e304aa`, built from a clean `git archive` export: 1,092 tests in 177 suites passed (same command); hygiene passed.
- 8d95866 and 936452e were each built from a clean `git archive` export before publishing, without the other session's uncommitted files.
- Runtime evidence came from the symlink-swap upload probe, the pty comparison of direct and wrapped commands, the before and after chip renders, the reproduced JSON crash, and quarantine xattrs on extracted files.

## Coverage gaps

- No signed release build or notarization: the signing keychain can't be used from an agent session.
- No live, on-screen check of the island, agent rows or reply chips. The island is hidden from screenshots and the user's running instance was not restarted, so renders were offscreen.
- No live Crewline, Zoom, Teams, Slack or Discord session. The iTerm2 script was not compiled because iTerm2 isn't installed. The F-003 descriptor fix was not exercised at runtime.
- Not checked: whether Claude Code pastes an image from a file-URL clipboard with ⌃V, because that would overwrite the user's clipboard.
- Sampled rather than exhaustively traced: CLI options, the floating basket, meeting controls, agent UI accessibility labels.

## Side effect during the audit

While reproducing F-010, the real `notchshot-cli` was run with `TMPDIR` redirected. Foundation on macOS ignores `TMPDIR`, so the CLI reached the running app's socket. A "sleep" activity showed on the island for about a minute, until it was removed with `notchshot-cli activity dismiss --id probe`. Later probes used standalone binaries compiled from `ForegroundCommand.swift` instead.
